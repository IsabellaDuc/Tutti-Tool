Un pannello di accessibilità gratuito. A free accessibility panel.

== Description ==

Sul sito compare un bottone rotondo in un angolo in basso. Chi visita apre il pannello e regola testo, spazi, contrasto, colori, animazioni, lettura ad alta voce. Le scelte restano nel suo browser: niente cookie, niente dati inviati, niente servizi esterni.

Il pannello aiuta chi legge, ma non rende il sito conforme alle norme sull'accessibilità (WCAG, European Accessibility Act): per quello il sito va controllato e sistemato.

A round button appears in a bottom corner of the site. Visitors open the panel and adjust text, spacing, contrast, colours, motion and read-aloud. Choices stay in their browser: no cookies, no data sent, no external services. The panel helps people read; it does not make the site compliant with accessibility rules.

Source, instructions and prompts for AI assistants: https://github.com/IsabellaDuc/Tutti-Tool

== Installation ==

1. Download tutti-tool.zip from https://github.com/IsabellaDuc/Tutti-Tool (do not unzip it).
2. In WordPress: Plugins → Add New → Upload Plugin → choose the file → Install Now → Activate.
3. Settings → Tutti Tool: corner, feedback email and, optionally, colours. Save.
4. Open the site: the button is in the bottom corner. If you do not see it, empty the cache of your caching plugin, if you have one.

1. Scarica tutti-tool.zip da https://github.com/IsabellaDuc/Tutti-Tool (senza aprirlo).
2. In WordPress: Plugin → Aggiungi nuovo → Carica plugin → scegli il file → Installa ora → Attiva.
3. Impostazioni → Tutti Tool: angolo, email per le segnalazioni e, se vuoi, i colori. Salva.
4. Apri il sito: il bottone è nell'angolo in basso. Se non lo vedi, svuota la cache del plugin di cache, se ne hai uno.
